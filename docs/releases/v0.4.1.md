# ESP32 Codex Notifications v0.4.1

Navigate画面で空き領域を上下にドラッグしてスクロールし、分・時間のスライダーを左右にドラッグして本体側の自動消灯時間を設定できるようにしました。0分0時間は本体側タイマーだけを無効にし、DesktopのAuto-dimには従います。中央の内容領域を帯ごとに描画して転送することで、操作中のちらつきを抑えました。ヘッダーを画面端まで連続させ、Bluetoothアイコンをその上に表示します。

長押し時にタッチ座標の計算が0除算で再起動する問題も修正しました。タッチとスクロールバーの判定、画面切り替え時の残像を修正しています。

## 検証

ホストのC++テスト18件、Pythonテスト13件、ESP32ファームウェアのビルドと配布物生成に成功しました。COM7基板へアプリ領域だけ書き込み、書込ハッシュを照合しました。所有者が空き領域スクロール、両スライダー、ヘッダーとBluetoothアイコンを確認し、ちらつき・表示欠け・再起動はありませんでした。RST後も設定値の保持とAgent/Commandのタップを確認しました。60秒のシリアル監視でも再起動を示すログは出ていません。

## 更新

既存の設定を保持する場合は `esp32-codex-notifications-v0.4.1-firmware.bin` をアプリ領域（0x10000）へ書き込んでください。`esp32-codex-notifications-v0.4.1-merged.bin` を0x0へ書くとBluetoothペアリングやタッチ調整を含むNVSが初期化されます。`SHA256SUMS.txt`で検証値を確認してください。
