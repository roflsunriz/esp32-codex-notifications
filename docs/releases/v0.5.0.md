# ESP32 Codex Notifications v0.5.0

Navigate画面の本体側自動消灯設定を、Appleのアラームに近い2列5行の縦ドラムへ変更しました。時・分は上下タップと縦ドラッグで選べます。保存済みの時間を変えず、画面だけを直ちに消す `SCREEN OFF` ボタンも追加しています。ボタン操作を復帰タッチとして再利用せず、消灯後の次のタッチは画面復帰だけに使います。DesktopのAuto-dim同期とNavigate画面のスクロールは従来どおり維持します。

## 検証

ネイティブテスト、Pythonの配布物テスト13件、ESP32ファームウェアビルド、静的解析、依存関係監査に成功しました。依存関係監査では文書化済みの限定除外以外に既知の脆弱性はありません。Notifications個体として指定されたCOM7基板では、全4MBの退避と読戻し照合、partition一致、アプリ領域の書き込みと独立した読戻し照合に成功しています。LCD上のドラム操作、即時消灯、復帰専用タッチは目視操作未確認です。

## 更新

既存のBluetoothペアリング、タッチ調整、画面方向を保持する場合は `esp32-codex-notifications-v0.5.0-firmware.bin` をアプリ領域（0x10000）へ書き込んでください。`esp32-codex-notifications-v0.5.0-merged.bin` を0x0へ書くとNVS設定が初期化されます。書き込み前に `SHA256SUMS.txt` と配布物のSHA-256が一致することを確認してください。
