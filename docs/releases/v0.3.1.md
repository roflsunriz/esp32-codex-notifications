# ESP32 Codex Notifications v0.3.1

画面操作とCodexステータス通知で発生していた、ILI9341表示のチラつきを抑える修正リリースです。

## 修正内容

- ボタンの押下・解放では、操作対象のボタンだけを再描画
- タブ切替では、内容領域と選択状態が変わる2つのタブだけを再描画
- Codexのステータス変更では、変化したAgentと通知欄だけを再描画
- BLE接続表示の変更では、右上の接続表示だけを再描画
- 呼吸エフェクトでは、呼吸中のAgentだけを90ms周期で更新
- 起動、画面回転、スリープ復帰以外の通常操作から全画面消去を除去

## ダウンロード

- `esp32-codex-notifications-v0.3.1-merged.bin`: 初回導入・初期化向けに0x0へ一括書き込みするイメージ。NVS設定を初期化します。
- `esp32-codex-notifications-v0.3.1-firmware.bin`: pairing、タッチ調整、画面方向を維持する0x10000更新用イメージ
- `esp32-codex-notifications-v0.3.1-bundle.zip`: 分割イメージ、manifest、書き込み手順
- `SHA256SUMS.txt`: 配布物のSHA-256

GitHub CLIがある場合、build provenanceは次のコマンドで検証できます。

```powershell
gh attestation verify esp32-codex-notifications-v0.3.1-merged.bin --repo roflsunriz/esp32-codex-notifications
```

## 更新時の注意

既存のBluetooth pairing、タッチ調整、画面方向を維持する場合は、`firmware.bin` を0x10000へ書き込んでください。更新後に各タブと全ボタンを操作し、CodexのAgent状態を変化させても画面全体が暗転しないことを確認してください。

## 既知の制約

- タブ切替では内容全体が変化するため、内容領域のみを一度再構築します。ヘッダーや画面全体の暗転は発生しません。
- ILI9341はSPIで逐次転送するため、描画対象そのものの色が切り替わる過程は短時間見える場合があります。
- Codex Micro互換通信はBLEのみで、Bluetoothペアリングが必要です。
- 非公開の互換プロトコルはCodex Desktop更新で変わる可能性があります。
