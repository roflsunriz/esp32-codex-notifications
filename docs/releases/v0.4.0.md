# ESP32 Codex Notifications v0.4.0

BOOT長押しの2点調整で、タッチ位置に加えて普段使うペンの押圧感度を測り、本体に保存します。以前の位置調整値は引き継ぎ、調整・保存に失敗した場合は旧値を保持します。

## 確認範囲

ホストテストとESP32ファームウェアビルドは成功しました。接続中のCodex Micro基板は書き換えておらず、新しい感度調整の実機操作は未検証です。抵抗膜へ接触できずペン割り込みが発生しない場合、閾値調整では反応しません。

## 更新

設定を保持する更新では `esp32-codex-notifications-v0.4.0-firmware.bin` をアプリ領域へ書き込みます。`esp32-codex-notifications-v0.4.0-merged.bin` を0x0へ書くと、ペアリングとタッチ調整を含むNVSが初期化されます。`SHA256SUMS.txt`でハッシュを確認し、[更新手順](../../how-to-update.md)に従ってください。
