# ESP32 Codex Notifications v0.1.1

黄色のダイヤル操作ボタンの左右割り当てを修正するパッチリリースです。

## 修正内容

- 左の黄色ボタンで値が減少するように修正
- 右の黄色ボタンで値が増加するように修正
- 左右の実際のBLEキー割り当てを固定する退行防止テストを更新

## ダウンロード

- `esp32-codex-notifications-v0.1.1-merged.bin`: 初回導入・初期化向けに0x0へ一括書き込みするイメージ。NVS設定を初期化します。
- `esp32-codex-notifications-v0.1.1-firmware.bin`: pairing、タッチ調整、画面方向を維持する0x10000更新用イメージ
- `esp32-codex-notifications-v0.1.1-bundle.zip`: 分割イメージ、manifest、書き込み手順
- `SHA256SUMS.txt`: 配布物のSHA-256

GitHub CLIがある場合、build provenanceは次のコマンドで検証できます。

```powershell
gh attestation verify esp32-codex-notifications-v0.1.1-merged.bin --repo roflsunriz/esp32-codex-notifications
```

## 更新時の注意

既存のBluetooth pairing、タッチ調整、画面方向を維持する場合は、`firmware.bin` を0x10000へ書き込んでください。

## 既知の制約

- Codex Micro互換通信はBLEのみで、Bluetoothペアリングが必要です。
- 非公開の互換プロトコルはCodex Desktop更新で変わる可能性があります。
