# ESP32 Codex Notifications v0.3.2

音声操作ボタンのマイクアイコンを正しい形状へ修正するパッチリリースです。

## 修正内容

- 角度指定の誤りで左半円になっていたマイクの外側アームを、下向きのU字へ修正
- 外側アームを5pxから2pxへ細くし、他のCommandアイコンと線幅を統一
- 塗りつぶしたマイク本体、左右支柱、中央ステム、台座を中心線に対して対称に配置
- 押下状態でも背景色のアンチエイリアスが混ざらない描画へ変更
- Command画面の固定記号とDesktop側のカスタム割り当ての関係をREADMEへ明記

## ダウンロード

- `esp32-codex-notifications-v0.3.2-merged.bin`: 初回導入・初期化向けに0x0へ一括書き込みするイメージ。NVS設定を初期化します。
- `esp32-codex-notifications-v0.3.2-firmware.bin`: pairing、タッチ調整、画面方向を維持する0x10000更新用イメージ
- `esp32-codex-notifications-v0.3.2-bundle.zip`: 分割イメージ、manifest、書き込み手順
- `SHA256SUMS.txt`: 配布物のSHA-256

GitHub CLIがある場合、build provenanceは次のコマンドで検証できます。

```powershell
gh attestation verify esp32-codex-notifications-v0.3.2-merged.bin --repo roflsunriz/esp32-codex-notifications
```

## 更新時の注意

既存のBluetooth pairing、タッチ調整、画面方向を維持する場合は、`firmware.bin` を0x10000へ書き込んでください。更新後にCommand画面の下段中央へ、左右対称なマイクアイコンが表示されることを確認してください。

## 既知の制約

- ILI9341は320×240ピクセルのため、アイコンは小さな線画で表現します。
- Codex Micro互換通信はBLEのみで、Bluetoothペアリングが必要です。
- 非公開の互換プロトコルはCodex Desktop更新で変わる可能性があります。
