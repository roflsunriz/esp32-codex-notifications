# ESP32 Codex Notifications v0.1.0

ESP32-2432S028RをCodex DesktopからCodex Micro互換デバイスとして利用する最初の実機検証済みリリースです。

## 主な機能

- 6つのAgent状態を色とアイコンで表示
- 完了、入力待ち、エラーの画面通知
- Agent切替、Fast、承認、拒否、フォーク、音声入力、送信
- 方向操作とダイヤル操作
- 物理BOOTボタンによる180度回転と2点タッチ調整
- 付属ペン向けの感度調整と、1回の接触が複数ボタンへ漏れない入力ロック
- 3回連続した安定座標だけを採用し、キャリブレーション後の単発ノイズによる誤操作を防止

## 対応ハードウェア

- ESP32-2432S028R
- ESP-WROOM-32 / ESP32-D0WD-V3
- ILI9341 320×240
- XPT2046抵抗膜タッチパネル

## ダウンロード

- `esp32-codex-notifications-v0.1.0-merged.bin`: 初回導入・初期化向けに0x0へ一括書き込みするイメージ。NVS設定を初期化します。
- `esp32-codex-notifications-v0.1.0-firmware.bin`: pairing、タッチ調整、画面方向を維持する0x10000更新用イメージ
- `esp32-codex-notifications-v0.1.0-bundle.zip`: 分割イメージ、manifest、書き込み手順
- `SHA256SUMS.txt`: 配布物のSHA-256

GitHub CLIがある場合、build provenanceは次のコマンドで検証できます。

```powershell
gh attestation verify esp32-codex-notifications-v0.1.0-merged.bin --repo roflsunriz/esp32-codex-notifications
```

## 既知の制約

- Codex Micro互換通信はBLEのみで、Bluetoothペアリングが必要です。
- 標準基板には姿勢センサーがないため、画面回転は物理BOOTボタンで行います。
- 非公開の互換プロトコルはCodex Desktop更新で変わる可能性があります。
