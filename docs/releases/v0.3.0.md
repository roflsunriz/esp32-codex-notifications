# ESP32 Codex Notifications v0.3.0

PCのスリープ、シャットダウン、Bluetooth切断後も画面を自動消灯する機能リリースです。

## 追加内容

- Codex MicroとのBLE接続が切れてから30秒後にILI9341表示とバックライトを自動的にOFF
- 30秒以内に再接続した場合は消灯をキャンセル
- 消灯後に再接続した場合は画面を自動復帰
- 切断中にタッチで復帰した場合は、そこから30秒後に再び自動消灯
- 未接続のまま起動した場合も30秒後に自動消灯
- `millis()` 周回を含む切断・再接続・タッチ復帰の退行防止テスト

## ダウンロード

- `esp32-codex-notifications-v0.3.0-merged.bin`: 初回導入・初期化向けに0x0へ一括書き込みするイメージ。NVS設定を初期化します。
- `esp32-codex-notifications-v0.3.0-firmware.bin`: pairing、タッチ調整、画面方向を維持する0x10000更新用イメージ
- `esp32-codex-notifications-v0.3.0-bundle.zip`: 分割イメージ、manifest、書き込み手順
- `SHA256SUMS.txt`: 配布物のSHA-256

GitHub CLIがある場合、build provenanceは次のコマンドで検証できます。

```powershell
gh attestation verify esp32-codex-notifications-v0.3.0-merged.bin --repo roflsunriz/esp32-codex-notifications
```

## 更新時の注意

既存のBluetooth pairing、タッチ調整、画面方向を維持する場合は、`firmware.bin` を0x10000へ書き込んでください。更新後にPCをスリープさせるかBluetooth接続を切り、30秒後の消灯と再接続時の復帰を確認してください。

## 既知の制約

- 切断中はDesktopのAuto-dim設定を取得できないため、切断時だけ固定30秒を使用します。
- Codex Micro互換通信はBLEのみで、Bluetoothペアリングが必要です。
- 非公開の互換プロトコルはCodex Desktop更新で変わる可能性があります。
