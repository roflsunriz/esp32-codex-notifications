# ESP32 Codex Notifications v0.3.3

Codex DesktopのCodex Micro Brightness設定へ、TFTバックライトの実輝度を同期するパッチリリースです。

## 修正内容

- `v.oai.rgbcfg` と `v.oai.thstatus` の共通brightnessを、GPIO 21の5kHz・8-bit PWMへ0〜255で反映
- 色またはeffectが有効な `b: 0` をBrightness 0%として扱い、完全消灯ゾーンの0とは区別
- ambient、keys、Agentの一部が消灯中でも、有効な照明指示から設定輝度を取得
- Auto-dimとBLE切断時の画面スリープでは、保存輝度に関係なくバックライトを確実に消灯
- 0%、10%、50%、100%と範囲外入力、Auto-dim中のdutyを固定する退行テストを追加

## 実機検証

ESP32-2432S028RとWindows版Codex Desktop `26.825.4187.0` で、Brightness変更がBLEの照明RPCとして到達し、次のdutyへ同期することを確認しました。

| Brightness | GPIO 21 duty |
| --- | --- |
| 0% | 0 |
| 10% | 26 |
| 50% | 128 |
| 100% | 255 |

検証後はCodex MicroのBrightnessを100%へ戻しています。

## ダウンロード

- `esp32-codex-notifications-v0.3.3-merged.bin`: 初回導入・初期化向けに0x0へ一括書き込みするイメージ。NVS設定を初期化します。
- `esp32-codex-notifications-v0.3.3-firmware.bin`: pairing、タッチ調整、画面方向を維持する0x10000更新用イメージ
- `esp32-codex-notifications-v0.3.3-bundle.zip`: 分割イメージ、manifest、書き込み手順
- `SHA256SUMS.txt`: 配布物のSHA-256

GitHub CLIがある場合、build provenanceは次のコマンドで検証できます。

```powershell
gh attestation verify esp32-codex-notifications-v0.3.3-merged.bin --repo roflsunriz/esp32-codex-notifications
```

## 更新時の注意

既存のBluetooth pairing、タッチ調整、画面方向を維持する場合は、`firmware.bin` を0x10000へ書き込んでください。更新後にCodex MicroのBrightnessを100%、50%、10%、0%へ変更し、画面の明るさが段階的に追従することを確認してください。

## 既知の制約

- 全Agentが未割り当てでambientとkeysも完全消灯している間は、Desktopが輝度設定値を含む有効な照明を送らないため、直前に観測した値を維持します。Agentの割り当てまたは状態変化後の照明更新で同期します。
- Codex Micro互換通信はBLEのみで、Bluetoothペアリングが必要です。
- 非公開の互換プロトコルはCodex Desktop更新で変わる可能性があります。
