# ESP32 Codex Notifications v0.2.0

Codex MicroのAuto-dim設定と同期して画面を自動消灯し、タッチで安全に復帰できる機能リリースです。

## 追加内容

- Codex Desktopで選んだAuto-dim時間に合わせてILI9341表示とバックライトを自動的にOFF
- 消灯中の最初のタッチは画面復帰だけに使い、タスク切り替えやコマンドの誤操作を防止
- Agent Keyの色または状態が変わった場合も画面を自動復帰
- 接続直後と復帰直後に複数回届く全消灯状態をAuto-dimと誤認しない同期状態機械と退行防止テスト

## ダウンロード

- `esp32-codex-notifications-v0.2.0-merged.bin`: 初回導入・初期化向けに0x0へ一括書き込みするイメージ。NVS設定を初期化します。
- `esp32-codex-notifications-v0.2.0-firmware.bin`: pairing、タッチ調整、画面方向を維持する0x10000更新用イメージ
- `esp32-codex-notifications-v0.2.0-bundle.zip`: 分割イメージ、manifest、書き込み手順
- `SHA256SUMS.txt`: 配布物のSHA-256

GitHub CLIがある場合、build provenanceは次のコマンドで検証できます。

```powershell
gh attestation verify esp32-codex-notifications-v0.2.0-merged.bin --repo roflsunriz/esp32-codex-notifications
```

## 更新時の注意

既存のBluetooth pairing、タッチ調整、画面方向を維持する場合は、`firmware.bin` を0x10000へ書き込んでください。更新後はCodex Desktopの `Settings > Codex Micro > Auto-dim` を30秒にして、消灯、最初のタッチによる復帰、次のタッチによる通常操作を確認してください。

## 既知の制約

- Auto-dim設定値そのものは非公開プロトコルで送信されないため、Desktopが期限到達時に送る全消灯照明状態を同期信号として使用します。
- Codex Micro互換通信はBLEのみで、Bluetoothペアリングが必要です。
- 非公開の互換プロトコルはCodex Desktop更新で変わる可能性があります。
